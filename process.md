# Development Process

I built a Language Translator mcp server with Node.js that consist of two main tools: language detection and text translation. For detection Claude recommended that I go with the franc library since it's lightweight and doesn't need any API keys. For the translation tool, I used the MyMemory API because it's free and easy to work with. Claude helped me keep everything in a single index.js file because the project didn't really need a complex folder structure.

Claude Code was super helpful throughout the process. When I asked it things like "detect the language of 'Hola amigo, cómo estás'" it knew exactly which MCP tool to call. I also used it to translate French text to English by prompting "Translate this text to English: 'Je suis très fatigué'" which worked out as well. At the end I just told it to commit everything to GitHub and make a README and PROCESS md file and it handled the whole thing.

The main issue I ran into was that when I started the server it just sat there doing nothing. No output, no confirmation, nothing. I honestly thought it was broken at first. It took me a bit to figure it out with Claude Code that MCP servers communicate over stdio so they're basically silent until a client actually connects and calls a tool. Once Claude Code connected with the server and started using the tools everything worked perfectly.

For the architecture, Claude basically broke it down like this. I made an MCP server instance from the SDK and registered my two tools using server.tool(). Each tool ended up getting a name, a description, a Zod input schema for validation, and an async handler function with the actual logic. Then at the bottom I hook up a StdioServerTransport and call server.connect() so the server listens over stdin/stdout. The .mcp.json file will then tell Claude Code how to launch and find my mcp server.

If I did this again I would probably add some kind of startup log or status indicator so it's more obvious that the server is actually running. I'd also use a better language detection library since franc struggles with short text inputs. I have to type out a paragraph, just for it to correctly guess the language being spoken.
